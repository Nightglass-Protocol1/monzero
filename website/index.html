Join the network

Turn spare CPU time into network security.

Run your own daemon, create a fresh Monzero wallet, and mine directly to an address you control. Solo mining rewards the machine that finds a block; rewards unlock after 60 blocks.

Keep it separate. Never reuse a Monero seed, keys, or wallet file with Monzero.

Mining pool

Prefer steady payouts? Mine with others at pool.monzero.org: PPLNS, 1% fee, payouts from 1 XMZ after 60 confirmations. Point XMRig at port 3333 (CPUs and laptops) or 5555 (servers and rigs), with your Monzero address as the login:

xmrig -o pool.monzero.org:3333 -u YOUR_MONZERO_ADDRESS -p rig1 -a rx/0

Windows mining

Mine XMZ on Windows.

Use the Windows command-line package from the download section. Extract the complete ZIP before running anything; do not launch files from inside the ZIP.

  1. 1
    Start and synchronize the node

    Double-click start-node.bat, allow the Windows Firewall prompt, and leave the window open. The launcher connects to node.monzero.org:6174 and the local RPC listens on 127.0.0.1:6175.

  2. 2
    Create a fresh wallet

    Run start-wallet-cli.bat, create a Monzero-only wallet, and record its recovery seed offline. Never reuse a Monero wallet or seed.

  3. 3
    Start CPU mining

    Open Command Prompt in the extracted folder and run start-mining.bat YOUR_MONZERO_ADDRESS 2. Replace the address and choose the number of CPU threads you want to use.

  4. 4
    Check rewards and stop

    Run balance in the wallet to see mined rewards; they unlock after 60 blocks. Run stop-mining.bat when you want to stop mining.

Questions

Before you begin.

Why is my mining balance still zero?

With solo mining you receive a coinbase reward only when your machine finds a block; simply hashing does not create a gradual balance. A found reward remains locked for 60 blocks. For smaller, regular payouts, mine at pool.monzero.org instead.

Is Monzero the same network as Monero?

No. Monzero is an independent experimental chain with a different genesis block, network ID, ports, address prefixes, ticker, and monetary policy.

Can I reuse my existing seed?

No. Create a new wallet and seed exclusively for Monzero. Reusing keys across forks can seriously damage privacy.

Is this a production release?

No. Genesis pre16 is experimental, unsigned, and unaudited prerelease software. It uses the pre10–pre15 chain and is incompatible with pre9 chain data.
