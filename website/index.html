Why Monzero

Built around participation.

01

Private transactions

Monzero inherits established privacy-focused transaction technology, including ring signatures, stealth addresses, and confidential amounts.

02

Consumer hardware

RandomX proof of work is designed for general-purpose CPUs, keeping participation open to ordinary computers.

03

Independent chain

XMZ has its own genesis block, network identity, address prefixes, ports, and monetary policy. It is not Monero.

Mining pool

Prefer sharing block rewards? Mine with others at pool.monzero.org: the pool reported PPLNS, a 1% fee, payouts from 1 XMZ and 60 confirmations when checked on 19 October 2026. Check the pool for current terms and payout status. Point XMRig at port 3333 (CPUs and laptops) or 5555 (servers and rigs), with your Monzero address as the login:

xmrig -o pool.monzero.org:3333 -u YOUR_MONZERO_ADDRESS -p rig1 -a rx/0

Windows mining

Mine XMZ on Windows.

Use the Windows command-line package from the download section. Extract the complete ZIP before running anything; do not launch files from inside the ZIP.

  1. 1
    Start and synchronize the node

    Double-click start-node.bat, allow the Windows Firewall prompt, and leave the window open. The launcher connects to node.monzero.org:6174 and the local RPC listens on 127.0.0.1:6175.

  2. 2
    Create a fresh wallet

    Run start-wallet-cli.bat, create a Monzero-only wallet, and record its recovery seed offline. Never reuse a Monero wallet or seed.

  3. 3
    Start CPU mining

    Open Command Prompt in the extracted folder and run start-mining.bat YOUR_MONZERO_ADDRESS 2. Replace the address and choose the number of CPU threads you want to use.

  4. 4
    Check rewards and stop

    Run balance in the wallet to see mined rewards; they unlock after 60 blocks. Run stop-mining.bat when you want to stop mining.

Monzero v1.0.0 · stable release · Windows GUI update

Download Monzero

Upgrade before block 21,000. v1.0.0 switches difficulty to LWMA at block 21,000 (hard fork 17). It is not a chain reset: coins, wallets and seeds are unchanged. Update your wallet and any node you run before that block: a pre16 wallet stops syncing there until it is updated, though no coins are at risk. Pool miners need do nothing.

Windows GUI update dated 18 October, plus stable v1.0.0 command-line builds for Windows and Linux x86-64. The GUI update keeps the v1.0.0 core and adds transparent teal branding, connection-startup improvements and simpler CPU mining controls, plus opt-in signed public wallet profiles. Existing wallets remain private unless the owner explicitly publishes a profile. Stable packages include the protocol whitepaper, release notes and the upgrade guide.

Original v1.0.0 packages: the release file lists their SHA-256 checksums and is signed (signature, release key, fingerprint 4C37C618789F86D81FEF28DF390AEFB735F270D6). Not yet independently audited; report issues to security@monzero.org.

Questions

Before you begin.

Why is my mining balance still zero?

With solo mining you receive a coinbase reward only when your machine finds a block; simply hashing does not create a gradual balance. A found reward remains locked for 60 blocks. For smaller, regular payouts, mine at pool.monzero.org instead.

Is Monzero the same network as Monero?

No. Monzero is an independent experimental chain with a different genesis block, network ID, ports, address prefixes, ticker, and monetary policy.

Can I reuse my existing seed?

No. Create a new wallet and seed exclusively for Monzero. Reusing keys across forks can seriously damage privacy.

Is this a stable release?

Yes. Monzero v1.0.0 is the first stable release. It continues the pre10–pre16 chain (no reset) and switches difficulty to LWMA at block 21,000, so anyone running their own node must upgrade before then. It has not yet been independently audited; report problems to security@monzero.org.
