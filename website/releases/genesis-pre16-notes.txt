CHANGES SINCE PRE15

- Wallets no longer fail on unmixable early outputs. Monzero's first three
  blocks paid old-style (pre-RingCT) rewards in fixed amounts that exist
  only a few times on chain. A wallet holding one could pick it for a
  transfer, and every transfer then failed with "not enough outputs for
  specified ring size = 16". The wallet now leaves such outputs out of
  transfers and sweeps. It works with the public node and does not reveal
  which amounts the wallet holds.
- The graphical wallet's Assets & NFT Studio matches monzero.org/app.
  Choose NFT, edition, collection or token, add artwork (fingerprinted on
  your computer, never uploaded), details and traits, see a live preview,
  save metadata.json and copy the wallet command. A verify panel checks a
  metadata file and image against their hashes. Metadata is identical to
  what the website produces for the same inputs. Issuing stays disabled
  until assets activate (hard fork 17).
- Everything in pre15 is included. Consensus identity and chain rules are
  unchanged from pre10 through pre15.

KNOWN LIMITATIONS

- A prerelease wallet that had selected the atomic-XMZ display unit cannot
  be opened; restore it from its recovery seed.
- The wallet file check cannot detect a Monero seed or private keys typed
  into Monzero's restore options. Never reuse them.
- The graphical wallet is built from GUI commit 0018a58f plus the Studio
  rework, the newest GUI code compatible with this core. Real-money DEX
  trading, cross-chain settlement, and native asset transfer/burn are
  unavailable.

TEST STATUS

All 23 ctest suites passed, including the full consensus replay and the
RPC functional tests; 1,318 unit tests passed. The wallet fix was used on
mainnet through the public node for single-recipient, multi-recipient and
multi-input transfers and a sweep, all confirmed. The Linux package passed
strict package checks (except the independent-reproduction attestation),
the digest-pinned container smoke test, and on Ubuntu 24.04 synced the
live chain through its launcher and refreshed a wallet created offline.
The Windows command-line package passed the native smoke,
network/launcher/mining, and wallet-lifecycle tests on Windows 11. The
graphical wallet package verified and launched on Windows 11; its Studio
page was tested separately.

Every archive was packaged twice with identical results, and a rebuild of
the core build directories reproduced the command-line executables byte
for byte. This is a same-machine check; reproduction by an independent
builder is still required.

Independent binary reproduction, release signing, code signing, and an
independent security review remain outstanding. Keep the prior verified
installation available for rollback.
