        For developers The monzero-metadata/1 standard

        The metadata hash committed on chain is the SHA-256 of the exact bytes of metadata.json. Studio writes the file canonically (keys sorted, no extra whitespace, UTF-8), so the same inputs always produce the same hash.

        • standard: always "monzero-metadata/1"
        • class: nft, edition, collection or fungible
        • name, description, creator, license, external_url
        • image, plus image_sha256, image_mime, image_bytes, image_width, image_height
        • attributes: a list of {"trait_type", "value"}
        • edition_size (editions), symbol and decimals (tokens), collection (member NFTs)

        Galleries must download the metadata, check its SHA-256 against the on-chain hash, then check the image against image_sha256 before showing anything. Treat every field as untrusted text. Never render SVG or HTML from metadata.
