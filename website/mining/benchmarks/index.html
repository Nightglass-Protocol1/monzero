Submit a measurement

Submit a pull request to the official source repository with a catalog record and supporting evidence, or open an issue there for review. No submission is automatically published. Read the submission and moderation requirements.

Include CPU/core/thread details, average RandomX H/s, measured power and measurement basis, OS, miner/version, date and test method. Remove wallet addresses, worker identifiers and personal details from logs. Never include keys or seed words.

Only wall-socket measurements enter the efficiency ranking. CPU-package readings exclude other system power and are labelled separately. Unknown power is unavailable, never zero. Differences in memory, tuning and thermal limits affect comparability.
