Monzero v1.0.0 · stable release · Windows GUI update

Download Monzero

v1.0.0 network upgrade. This release switches difficulty to LWMA at block 21,000 (hard fork 17), continuing the existing chain. Older pre16 nodes stop syncing at that height until updated. Read the upgrade guide and current status.

Windows GUI update dated 18 October, plus stable v1.0.0 command-line builds for Windows and Linux x86-64. The GUI update keeps the v1.0.0 core and adds transparent teal branding, connection-startup improvements and simpler CPU mining controls, plus opt-in signed public wallet profiles. Existing wallets remain private unless the owner explicitly publishes a profile. Stable packages include the protocol whitepaper, release notes and the upgrade guide.

Original v1.0.0 packages: the release file lists their SHA-256 checksums and is signed (signature, release key, fingerprint 4C37C618789F86D81FEF28DF390AEFB735F270D6). Not yet independently audited; report issues to security@monzero.org.
