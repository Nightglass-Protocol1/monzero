How these numbers are made

A collector next to node.monzero.org reads that node's own peer list and open connections. It looks up each public IP in an offline IP-to-country database and sends only the per-country totals to this website. IP addresses are not stored or published, and Tor and I2P peers are not counted.

  • Accepting connections: nodes the public node completed a handshake with in the last 24 hours.
  • Connected now: open connections at collection time, including nodes behind firewalls.
  • Observed: distinct addresses in either group.

These are approximate. A country lookup can be wrong (VPNs, hosting providers, outdated database), one node can use several addresses, and one vantage point does not see every node. This is not a count of users or miners.
